# Testing and Experimental Records

This directory is intended to maintain experimental records and supporting evidence for the IoT-Based Smart Energy Monitoring System.

The project-level calibration and testing methodology is documented in:

`docs/calibration-and-testing.md`

## Test Records

The file `test-record-template.csv` provides a format for recording actual measurements during system testing.

Test records should include the operating condition, reference measurement, system measurement, calculated error, and observations.

Only measurements obtained during actual testing should be entered. No experimental results or accuracy values are assumed in this repository.
