# Project Overview

## 1. Project Title

IoT-Based Smart Energy Monitoring System

## 2. Introduction

The Smart Energy Monitoring System is an IoT-based project developed to monitor electrical energy consumption and provide users with accessible information about their electricity usage.

The system uses an ESP32 microcontroller integrated with voltage and current sensing modules to acquire electrical measurements. The acquired data is processed to determine electrical parameters such as voltage, current, power, energy consumption and power factor.

The system provides local monitoring through a 16×2 I2C LCD and remote monitoring through Firebase cloud integration and a mobile application.

## 3. Project Motivation

The project was initiated to address the limited accessibility of detailed, real-time household electricity consumption information.

By combining embedded systems, electrical sensing and IoT connectivity, the project aims to make energy consumption easier to monitor and understand.

## 4. Core Functionalities

- Voltage measurement.
- Current measurement.
- Power calculation.
- Energy consumption monitoring.
- Power factor monitoring.
- Estimated electricity bill calculation.
- Local LCD display.
- Cloud-based data communication.
- Mobile application interface.

## 5. Technology Stack

**Hardware**
- ESP32 microcontroller
- ZMPT101B voltage sensor
- ACS712 current sensor
- 16×2 I2C LCD
- Custom-designed PCB

**Software**
- Arduino IDE
- Embedded C/C++
- Firebase Realtime Database
- MIT App Inventor
